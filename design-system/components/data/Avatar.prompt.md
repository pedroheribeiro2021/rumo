Initials-only avatar — Rumo has no photo upload for trip members yet (members can be name-only, no account). Color is deterministic per name so the same person always renders the same color across a trip.

```jsx
<Avatar name="Ana Costa" size="md" />
<Avatar name="Pedro" size="lg" ring />
```

`ring` adds a subtle brand-tinted ring, e.g. to mark "you" in a members list.
